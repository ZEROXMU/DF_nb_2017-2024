# Epidemiological characteristics and transmission dynamics of dengue in Ningbo City, China before, during, and after the COVID-19 pandemic interventions

Data and code repository for the study of dengue epidemiology and transmission dynamics in Ningbo City, China, 2017-2024.

## Dataset Overview
This repository provides the Figshare data file, the analysis code, and a de-identified dataset used to reproduce the main visualizations and results of the study entitled “Epidemiological characteristics and transmission dynamics of dengue in Ningbo City, China before, during, and after the COVID-19 pandemic interventions.” The materials cover dengue epidemiology, mosquito vector density, public health and social measures (PHSMs), and transmission dynamics in Ningbo, Zhejiang Province, from 2017 to 2024.

The dataset and code are intended to support reproduction of the study, further public health research, policy development, disease prediction, and teaching. Researchers may adapt the dataset and code for additional analyses according to their research needs.

## Data Content
### 1. Case Surveillance Data
Time Period: January 1, 2017 - December 31, 2024
Coverage Area: All districts of Ningbo Municipality

### 2. Vector Density Surveillance Data
Monitoring Sites: Breteau Index (BI) of all districts of Ningbo Municipality
Time Period: April 1, 2017 - November 30, 2024

### 3. Key Epidemiological Investigation Information
Intensity of Public Health and Social Measures (PHSMs)
Time Period: January 1, 2017 - December 31, 2024
Coverage Area: Citywide

### 4. Demographic data
The number of people with different characteristics
Time Period: January 1, 2017 - December 31, 2024

## Repository Contents
1. README.md (this file)
2. Figshare.xlsx (Data file uploaded to Figshare)
3. Figshare.ipynb (Analysis code uploaded to Figshare for reproducing the main study visualizations and related analyses)
4. de-identified data.xlsx (De-identified dataset used for research reproduction, further analysis, and teaching)
5. gadm41_ningbo_2.json (Administrative boundary map from GADM: https://gadm.org/)
6. `environment_info.txt` provides the reference environment and the complete list of installed Python distributions.

## Quick Start
1. Download `Figshare.xlsx`, `Figshare.ipynb`, `de-identified data.xlsx`, and `gadm41_ningbo_2.json` from Figshare.
2. Refer to the `environment_info.txt` file to configure the environment and install the Python program.
3. Open `Figshare.ipynb` in Jupyter Notebook.
4. Run the notebook cells with the relevant data files to reproduce the main study visualizations and results.
5. Researchers may modify the code or use the de-identified dataset for additional analyses and teaching purposes, subject to the terms of the license and applicable regulations.

## Important Notes
The accompanying dataset is de-identified, with personal information removed, and is provided together with the code for research replication, further analysis, and teaching.

The original individual-level case data contain personal information and are protected under the Law of the People's Republic of China on the Prevention and Treatment of Infectious Diseases. The original data are not included in this repository. Researchers who require access should contact the corresponding author and obtain the necessary ethics approval before requesting the data.


If you use the dataset or code, please cite the study after it has been formally published. Before formal publication, please contact the corresponding author for the appropriate citation information.
